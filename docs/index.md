| やりたいこと | 場所 |

| エージェント運用のルールを知る | [framework/](framework/) |

| 調査メモを残す / 読む（情報ソース付き） | [planning/research/](planning/research/) |
| 要件定義を残す / 読む | [planning/requirements/](planning/requirements/) |
| なぜそう決めたかを残す / 読む | [decisions/](decisions/) |
| 作業サマリーを残す / 読む | [work-notes/](work-notes/) |
| プロダクト仕様・ロードマップ | [knowledge/product/](knowledge/product/) |
| アーキ・runtime・secret・テスト方針 | [knowledge/engineering/](knowledge/engineering/) |
| ビジネスモデル・価格・提供形態 | [knowledge/business/business-model/](knowledge/business/business-model/) |
| マーケティング施策 | [knowledge/business/marketing/](knowledge/business/marketing/) |
| ブランディング（トーン・ロゴ・命名） | [knowledge/business/branding/](knowledge/business/branding/) |

## レイヤーの考え方

- **framework/** = 運用ルール（メタ）
- **knowledge/** = 今の事実（stock）
- **planning/** = 企画中の成果（flow）
- **decisions/ · work-notes/** = 履歴（log）

企画（調査・要件）と実作業（実装）は分ける。詳細は [framework/knowledge-base.md](framework/knowledge-base.md#企画と実作業の分離)。

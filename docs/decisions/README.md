# decisions — 意思決定記録

仕様判断、採用した trade-off、却下した案、再検討条件を、**情報ソースと理由を添えて**簡潔に残す。

## ファイル名

```text
YYYY-MM-DD-short-topic.md
```

## テンプレート

```md
# 判断: <短いタイトル>

## 日付
YYYY-MM-DD

## 背景 / 課題
-

## 選択肢
-

## 決定
-

## 理由
-

## 情報ソース
- <URL / 参照した repo・記事・skill・社内資料など>

## 影響範囲
- 更新した docs / コード / 対象カテゴリ

## 却下した案・再検討条件
-
```

**情報ソースは必須。** 企画で参照した URL・ツール・資料を残し、根拠を追跡可能にする。詳細は [../framework/knowledge-base.md](../framework/knowledge-base.md#意思決定の型-docsdecisions)。

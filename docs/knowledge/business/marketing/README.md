# marketing — マーケティング

施策、チャネル、キャンペーン、主要メッセージを置く。

- ファイル名: `<topic>.md`（例: `channels.md`, `launch-campaign.md`, `messaging.md`）
- frontmatter 例:
  ```yaml
  ---
  title: <タイトル>
  status: planned | running | done
  updated: YYYY-MM-DD
  ---
  ```
- 更新トリガー: 施策・チャネル・キャンペーンの追加や変更（主担当: 担当者）
- 実施の可否や予算に関わる意思決定は [../../../decisions/](../../../decisions/) に残す。

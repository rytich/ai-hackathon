# competitive — 競合調査

競合の調査結果、比較、ポジショニングを置く。**情報ソース（URL・調査日）を必ず添える。**

- ファイル名: `<competitor-or-topic>.md`（例: `competitor-x.md`, `positioning.md`）
- frontmatter 例:
  ```yaml
  ---
  title: <タイトル>
  status: active
  updated: YYYY-MM-DD
  sources: [<URL>, <URL>]
  ---
  ```
- 更新トリガー: 競合の新情報（主担当: 調査担当）
- 一次調査のメモは [../../../planning/research/](../../../planning/research/) に置き、確定した比較・示唆をここへ反映する。

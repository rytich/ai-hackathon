# (例) メール通知機能の要件

> これは書き方の記入例です。実データではありません。

## 背景
[調査](../research/_example-research.md) の結果、初回はメール通知のみを提供する。

## スコープ
- やる: 会員登録完了メール、パスワード再設定メール
- やらない: プッシュ通知、SMS、マーケティングメール配信

## 受け入れ条件（検証可能な形）
- 登録完了後 1 分以内に確認メールが届く
- 再設定リンクは 30 分で失効する
- 送信失敗時はリトライされ、失敗はログに残る

## 制約
- 既存のメール配信 API を利用する（新規契約しない）

## 未決事項
- 配信量増加時の価格（[調査](../research/_example-research.md) の未確認事項）

→ 承認後に実装。確定仕様は [../../knowledge/product/](../../knowledge/product/) に反映する。

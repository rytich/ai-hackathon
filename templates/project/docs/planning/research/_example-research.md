# (例) 通知チャネルの選定調査

> これは書き方の記入例です。実データではありません。

## 目的
初回リリースで採用する通知チャネル（メール / プッシュ / 両方）を決めるための一次調査。

## 調べたこと
- 主要メール配信 API の到達率・価格・実装コスト
- プッシュ通知の実装コストとオプトイン率の相場

## わかったこと
- メールは実装が最も早く、既存の会員基盤で到達可能。
- プッシュはオプトイン率が低く、初回では ROI が見合わない。

## 示唆
- 初回はメールのみ。プッシュは指標を見てから検討。

## 未確認事項
- 配信量が増えた場合の価格逓減（要見積り）

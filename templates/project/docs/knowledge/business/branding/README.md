# branding — ブランディング

トーン&マナー、ロゴ、命名規則、ボイス&トーンなど、対外表現の基準を置く。

- ファイル名: `<topic>.md`（例: `voice-and-tone.md`, `naming.md`, `visual-identity.md`）
- frontmatter 例:
  ```yaml
  ---
  title: <タイトル>
  status: active
  updated: YYYY-MM-DD
  ---
  ```
- 更新トリガー: トーン&マナー・ロゴ・命名規則の変更（主担当: 担当者）
- 画像などのアセットは同フォルダに置くか、保管先へのリンクを本文に書く。

# business-model — ビジネスモデル

価格、提供形態、収益構造、主要 KPI など、事業の骨格を置く。

- ファイル名: `<topic>.md`（例: `pricing.md`, `revenue-model.md`, `kpi.md`）
- frontmatter 例:
  ```yaml
  ---
  title: <タイトル>
  status: active
  updated: YYYY-MM-DD
  links: [../../../decisions/YYYY-MM-DD-xxx.md]
  ---
  ```
- 更新トリガー: 価格・提供形態・事業方針の変更（承認: Human Approver）
- 変更理由と根拠は [../../../decisions/](../../../decisions/) に残し、ここからリンクする。

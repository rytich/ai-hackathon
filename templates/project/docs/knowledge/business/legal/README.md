# legal — 法務・規制

利用規約、準拠法令、業界規制、プライバシー方針などを置く。

- ファイル名: `<topic>.md`（例: `terms.md`, `privacy.md`, `regulations.md`）
- frontmatter 例:
  ```yaml
  ---
  title: <タイトル>
  status: active
  updated: YYYY-MM-DD
  sources: [<条文・ガイドラインの URL>]
  ---
  ```
- 更新トリガー: 規約・法令・プライバシーの変更（承認: Human Approver）
- 法的判断は必ず [../../../decisions/](../../../decisions/) に情報ソース付きで残す。エージェントは法的助言を確定させず、Human Approver に渡す。

# support — サポート

FAQ、カスタマーサポートの方針、定型応答（テンプレート）を置く。

- 主なファイル:
  - `faq.md` — よくある質問と回答
  - `support-policy.md` — 対応方針・エスカレーション基準
  - `canned-responses.md` — 定型応答テンプレート
- frontmatter 例:
  ```yaml
  ---
  title: <タイトル>
  status: active
  updated: YYYY-MM-DD
  ---
  ```
- 更新トリガー: 問い合わせ傾向の変化・定型応答の追加（主担当: サポート担当）
- 頻出する問い合わせから見つかった課題は、プロダクト側にもフィードバックする（[../product/](../product/) や [../../decisions/](../../decisions/)）。
